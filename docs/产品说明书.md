# MOTILAI 产品说明书

## 产品概述

MOTILAI 是一个支持流式对话、附件、语音听写以及助手、知识库和工具扩展的 AI 对话应用，并提供管理员后台用于维护用户、模型供应商和系统资源。

## 管理后台

管理员登录后可通过侧边栏访问用户管理、模型供应商、助手、知识库、工具和系统配置。后台各页面使用紧凑高度的 header，面包屑导航居左显示，不再在 header 中展示额外品牌标题或右上角用户头像和名称。页面内容使用更宽的可用区域，表格列表采用单双行浅色区分并显示序号；用户和资源列表支持复选框、全选及批量删除，系统管理员账号不可被选中或删除。

系统配置中的 Logo 和 Favicon 通过点击图片预览区域选择本地图片，并支持清空已选图片；用户头像采用相同的点击选择与清空交互。图片仅以预览形式展示，配置页面和用户编辑界面均不显示图片 URL 或 `data:image` 文本。

模型供应商编辑抽屉支持根据当前 Base URL 和 API Key 获取模型列表，默认模型仅能从获取结果中下拉选择。新建供应商可在保存前获取模型，编辑已有供应商时留空 API Key 会继续使用已保存的凭据。管理接口不返回 API Key 或脱敏片段，页面仅展示“已配置”或“未配置”，密码输入框也不提供明文查看入口。

## 登录与注册

登录和注册页面采用独立于后台的浅灰绿色背景，并以白色卡片承载认证表单。品牌标识、页面眉题、主标题和说明文字居中显示；卡片使用细边框、顶部品牌色线和层次阴影强化视觉区隔，输入框支持占位提示、悬停和聚焦反馈。

## 部署与服务运维

生产环境通过 Docker Compose 运行 PostgreSQL 和 MOTILAI 应用，并由 systemd 提供统一的服务管理入口。`motilai-chat.service` 的工作目录为项目根目录 `/home/ubuntu/softwares/motilai`，该目录包含 `docker-compose.yml`；旧的 `/home/ubuntu/softwares/motilai/chat-ui` 路径已失效，不应再用于服务配置或运维命令。

更新服务单元后，需要执行 `sudo systemctl daemon-reload`，再使用 `sudo systemctl restart motilai-chat` 重启服务，并通过 `sudo systemctl status motilai-chat` 检查运行状态。

服务单元安装命令为 `sudo install -m 0644 deploy/motilai-chat.service /etc/systemd/system/motilai-chat.service`；安装时应在项目根目录 `/home/ubuntu/softwares/motilai` 执行。
